# Tile Floor Calculator

Веб-инструмент для черчения помещения, подбора раскладки плитки и оценки количества целых плиток и обрезков.

## Возможности

- Рисование контура помещения на canvas.
- Привязки к сетке, гайдлайнам и осям.
- Ввод размеров чертежа в мм, см или м.
- Раскладки: прямая, со смещением, диагональная, елочка.
- Размер плитки в мм, зазор, запас, смещение раскладки.
- Зум колесом мыши и панорамирование зажатым колесом.
- Undo/redo, удаление последней точки, добавление точки в отрезок.
- Импорт и экспорт проекта в JSON.
- Автосохранение в браузере.

## Требования

- Node.js 24
- pnpm 11.0.8

Если pnpm не установлен:

```bash
corepack enable
corepack prepare pnpm@11.0.8 --activate
```

## Запуск

```bash
pnpm install
pnpm dev
```

Локальный адрес:

```text
http://127.0.0.1:5173/
```

Остановить dev server можно через `Ctrl+C` в терминале, где запущен `pnpm dev`.

## Проверки

```bash
pnpm test
pnpm build
```

## Публикация

Приложение статическое. Для production-сборки:

```bash
pnpm build
```

Публиковать нужно содержимое папки `dist`.

Подходящие хостинги:

- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages

## Smoke Checklist

Перед публикацией вручную проверить:

- Страница открывается без ошибок.
- Можно нарисовать и замкнуть помещение.
- Привязки `гайдлайны`, `оси`, `сетка` включаются независимо.
- Размер плитки, зазор, запас и масштаб меняют расчет.
- Все типы раскладки отображаются.
- Зум и панорамирование работают.
- `Ctrl+Z` и `Ctrl+Shift+Z` работают.
- Экспортированный JSON импортируется обратно.
- После обновления страницы состояние восстанавливается.

## Ограничения

Расчет является оценочным. Обрезки группируются алгоритмически, а реальные потери зависят от способа укладки, направления реза, брака материала и решений мастера. Для ремонта стоит закладывать запас и сверять результат с исполнителем.
